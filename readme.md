# SpendStack

A modern cross-platform personal finance application built as a learning and portfolio project.

## Tech Stack

- Next.js
- Expo
- React
- React Native
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- PostgreSQL
- Zod
- React Hook Form
- TanStack Query
- Zustand
- Recharts
- pnpm
- Turborepo
